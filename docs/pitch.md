### 0:24–0:30 證據與團隊

**中文 85 字＋5 個英文詞（約 92 音節），以 4–4.5 字／秒唸約 20–23 秒，留 7–10 秒給停頓與畫面。實際計時兩次；超過 30 秒就砍「免費、雙語」或第二句，不要加速。**

## 3. 評審問答（不計時，30 秒簡報後使用）

| 問題 | 短答 | 證據 |
|---|---|---|
| 資料是真的嗎？ | 是，三組 NASA 資料，賽前快照 | `docs/data-sources.md`；DONKI X2.7、REMS 冷週、Image Library 7 張 |
| 為什麼說是快照？ | 場地網路不可靠；快照不冒充即時 | 介面標 `snapshot, not live` |
| 你們是不是賽前就做好遊戲？ | 沒有。賽前只有研究、資料、品牌與文件；程式從 11/14 09:00 開始 | repo 的 commit 時間戳；`docs/ai-disclosure.md` 第 7 節 |
| 為什麼是貓？ | 與團隊前作同一組三隻貓，兒童記得住；貓是船員，不是吉祥物 | 角色設定與語氣 guide |
| 教育性夠嗎？ | 學習目標是「取捨與理由」，不是背名詞；20 張知識卡可選讀 | `docs/glossary.md`、`docs/event-cards.md` |
| 會不會太難？ | 三個選項都顯示代價；失敗是「任務暫停」，不責備 | `docs/wireframes.md`、`docs/playtest.md` |
| 為什麼只有橫向？ | 16:9 場景與三貓同框需要橫向；直向顯示旋轉提示 | PLAN 6.8 |
| 無障礙怎麼做？ | 鍵盤操作、44px 觸控、對比 AA、200% 縮放、減少動效 | PLAN 7.2、`docs/qa-checklist.md` 第 6 節 |
| AI 用了多少？ | 研究整理、文件、程式骨架、圖像；事實逐一查核，runtime 不用 AI | `docs/ai-disclosure.md` |
| 火星沒有磁場，為什麼有 Kp？ | Kp 是地球指數，遊戲只當風暴強度的簡化代理，面板有寫 | `docs/glossary.md` 第 3 節 |
| 有讓小孩測過嗎？ | 有，11/14 共 【1】 位，修正 【N】 個問題 | `docs/playtest.md` 修復紀錄 |
| 下一步？ | 即時 DONKI、教室模式、更多知識卡 | — |

**回答原則：** 不會的就說「這我們沒有做」，不要編。評審對「誠實但範圍小」的評價，通常高於「什麼都說有」。

## 4. 失敗備案

| 狀況 | 處理 |
|---|---|
| 網站打不開 | 直接播 30 秒影片；沒有影片就播本機 `dist/` |
| 平板沒電 | 用筆電；版面已驗收 1440×900 |
| 網路斷 | 影片與快照都可離線 |
| 時間被砍到 20 秒 | 用 `docs/video-script.md` 第 6 節的 20 秒旁白 |
| 被問倒 | 「這我們沒做，但我們的假設是⋯⋯」然後回到已知證據 |
