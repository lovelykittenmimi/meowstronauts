# 兒童 Playtest 計畫

> 最後更新：2026-11-12（因時間不足改為 1 位兒童、11/14 17:30 單場；不追加 11/15）
> 對象：7–12 歲兒童，1 位
> 長度：20 分鐘（含說明與事後訪談）

---

## 1. 我們想回答的三個問題

1. **選擇有沒有被理解？** 兒童能不能說出「我選了 A，所以電力變少、氧氣變多」這種取捨，而不是只挑顏色或貓。
2. **說明有沒有被找到？** 兒童會不會主動點虛線字？找不找得到背包？需不需要大人指？
3. **七個 sol 會不會太長？** 兒童在第幾個 sol 開始分心、亂點、或想離開？

> 這三題沒過，就算遊戲能跑完也不算出貨。知識卡可以砍到 8 張，但「找得到、看得懂」不能砍。

## 2. 參與者與倫理

- 1 位兒童（已確認：團隊成員，12 歲；家長兩人在場）。原本的 3 位年齡分布取消，時間不足，不追加第二位。
- **家長在場／口頭同意**：測試前向家長說明「這是測試遊戲，不是測試小孩」；可隨時停止；不錄影、不錄音。
- 文件只用 C1 代號，不寫姓名、學校、照片。
- 不給提示、不代打、不說「你點那個虛線字看看」。真的卡住時只問：「你現在想做什麼？」最多提示一次，並記錄「需要提示」。
- 計時 20 分鐘一到就停，即使沒玩完；沒玩完本身就是資料。
- 結束給一張貼紙或小獎勵，不論表現。

## 3. 場地與設備

| 項目 | 內容 |
|---|---|
| 裝置 | 平板橫放 1024×768 為主；備用手機 844×390 橫放。只測一台，不追三種尺寸 |
| 輸入 | 觸控為主；若用筆電，確認滑鼠＋鍵盤都能操作 |
| 瀏覽器 | Chrome 或 Safari 最新版，先清 cache |
| 錄影 | 不錄影；只做紙筆紀錄（時間不足，減少行政） |
| 計時 | 手機計時器，記錄每個 sol 的開始時間 |
| 記錄 | 本文件的第 6 節表格，一張 |

> 測試前 10 分鐘：確認網路、音量、進度重置（清 localStorage），並把瀏覽器縮放設為 100%。

## 4. 20 分鐘流程

| 時間 | 內容 | 主持人的話（照念即可） |
|---:|---|---|
| 0:00–0:02 | 暖身、說明 | 「這是一個還在做的火星遊戲，沒有標準答案。你覺得無聊或看不懂，都可以直接說，這是在幫我們。」 |
| 0:02–0:04 | 開場分鏡 | 「直接開始玩，我會在旁邊看，不會幫你。」**開始計時** |
| 0:04–0:14 | 自由遊玩（目標 sol 1–7） | 只觀察、不指導；兒童說話時簡短回應「嗯」「然後呢」 |
| 0:14–0:17 | 事後訪談 | 見第 5 節，一次一題，不追問成考試 |
| 0:17–0:20 | 收尾 | 「最喜歡哪一隻貓？」給貼紙，感謝 |

**如果兒童 10 分鐘就到達任務報告：** 讓他重玩一次，觀察是否跳過開場、是否嘗試不同選項。
**如果兒童 5 分鐘就想離開：** 不強留，記錄離開的 sol 數與最後一句話。

## 5. 事後訪談（一次一題）

1. 「你剛剛做了什麼？用你自己的話說一次。」（測理解，不測記憶）
2. 「你選的那個，讓哪個東西變少？哪個變多？」（測取捨）
3. 「畫面裡有虛線的字，你有看到嗎？那是做什麼的？」（測術語入口；若沒看到，拿出畫面指出，再問「你覺得這是什麼？」）
4. 「如果現在要再看一次剛剛的解釋，你會去哪裡找？」（測背包可發現性）
5. 「哪一個 sol 最無聊？為什麼？」（測節奏）
6. 「你會想再玩一次嗎？想試哪裡不一樣？」（測重玩動機）
7. 給家長／兒童：「有沒有哪個字你看不懂？」（收集生詞，不回饋答案）

> 不要問「你覺得好玩嗎」單題，兒童會客氣。用「最無聊的是哪裡」比較容易得到真話。

## 7. 判斷標準：什麼要修、什麼只是紀錄

| 嚴重度 | 定義 | 處理 |
|---|---|---|
| P0 阻斷 | 兒童無法完成一局，或卡在同一處超過 5 分鐘 | 11/14 當晚修 |
| P1 理解 | 兒童誤解同一個資源或選項後果 | 改文案或圖示，11/15 上午前 |
| P2 發現性 | 需要提示才找到虛線字／背包 | 加大入口、加一次提示，11/15 上午前 |
| P3 偏好 | 只出現一次、不影響完成 | 記錄，不修 |

- 只有 1 位兒童，不等待「2 位以上」才修；P0/P1 出現 1 次就處理，P2/P3 記錄。
- 修完後用自己玩重測「原本卡住的那一步」，不追加兒童場。
- 平衡問題（太難／太簡單）不在 playtest 修，交給 10,000 局模擬與難度設定。
