## 3. 核心流程（從頭玩一局）

- [ ] 新遊戲 → 開場分鏡 → 三個 tap 組出 HUD。
- [ ] 開場 6 幕（或 3 幕降級版）可完整跑完；進度點數目與實際幕數一致，不顯示不存在的幕。
- [ ] 旁白（4 句）顯示在畫面上方的深色字卡、字級大於貓咪台詞；「Then they hit us.」下一步會把天線與十二分鐘那句疊在同一張卡上，不遮住 Skip、播放鍵與下方面板。
- [ ] 旁白時沒有台詞的對話／無線電面板會顯示三隻貓的頭像，表情符合當下情境（迫降吃驚、沒冰箱無奈）；短螢幕上面板不壓到上方的旁白卡。
- [ ] 幕 2 動畫本體 18±1 秒；18 秒後顯示「繼續」，停在最後一格，不自動跳。
- [ ] 「跳過」可用，跳過後直接進 sol 1，HUD 完整。
- [ ] 七個 sol 都能推進；sol 4 固定出現 S1 太陽閃焰警報卡（不是「太陽風暴」卡）。
- [ ] Sol 切換列：已完成的 sol 可切回去看回顧，未到的 sol 反灰不可點；目前 sol 高亮；回顧不改變任何數值，切回目前 sol 可繼續。
- [ ] 著陸練習：Sol 列右側的〔🚀 著陸練習〕可開啟小遊戲，關閉後回到原本畫面，不影響任務與資源。
- [ ] 每個選項都顯示代價；點擊後有回饋，不會連點兩次。
- [ ] 貓咪專長：每隻 2 次，用完顯示不可用；使用時機在選擇後、結算前。
- [ ] 風險選項：失敗時套用失敗效果，不是疊加。
- [ ] 資源歸零：扣健康、顯示提示，不會變成負數。
- [ ] 任務報告：1 星與 3 星都完整；資源曲線 7 點；貓咪評論與結果一致。
- [ ] 再玩一次：重置資源與事件，**不重置**背包收藏。
- [ ] 重新整理：背包收藏仍在（`localStorage`）；遊戲進度重置是預期行為。

### 3.1 事件條件（MVP 12 張）

> 規格見 `docs/event-cards.md` §3.2–§3.3。用開發模式 `?debug=deck` 顯示「今日候選池／被排除原因」來檢查；`?debug=deck` 不得出現在一般模式與錄影畫面。

- [ ] Sol 4 固定出現 S1；其他 sol 不重複出現 S1。
- [ ] P4「冷週暖氣」只在 `cold_snap` 或 `severe_cold` 的 sol 出現；晴天暖週不出現。
- [ ] 資源良好時不硬塞生存卡：`power ≥ 80` 不抽 P1、`lifeSupport ≥ 80` 不抽 L1／L2、`≥ 75` 不抽 L3、`shield ≥ 80` 不抽 S2、`food ≥ 5` 不抽 F1／F3。
- [ ] `shield < 60` 時 S2 可出現；S1 後的 Sol 5–6 也可出現，但 `shield ≥ 80` 仍排除。
- [ ] S3 只在 Sol 3–5、已收到 `flareForecast`、且 `shield < 75` 時出現。
- [ ] C1 只在 `commsWindow` 開啟後出現；SC2 只在 `science < 4` 時出現。
- [ ] 候選不足 6 張時，先放寬資源門檻 10；仍不足就重複合格卡，**不得**塞入不符合 `when` 的卡。
- [ ] 事件卡的 `when` 與 `src/game/conditions.ts` 的 predicate 名稱一致；沒有只寫在文件、程式沒實作的條件。
- [ ] 影片路徑 `?video=s1` 的 Sol 4 不受條件影響，S1 一定在。

## 4. 知識卡與背包

- [ ] 行內虛線字可點，且點擊區不窄於 32px。
- [ ] 每張事件卡最多 2 個術語；同一術語不重複解釋。
- [ ] drawer 內容順序：術語 → 一句話 → 為什麼重要 → 來源 → 相關 → 收入背包。
- [ ] 來源連結可點，開新分頁，指向 NASA 網域。
- [ ] ［收入背包］後按鈕變「已在背包 ✓」，仍可重讀。
- [ ] 背包 tab 數字正確（例：太空天氣 5/7）。
- [ ] 未收藏卡片顯示灰剪影＋「?」，不劇透名稱。
- [ ] 背包 4 欄（<680 為 3 欄）；20 格都放得下。
- [ ] 所有 `{{termId}}` 都有對應卡；沒有漏字或顯示原始 token。
- [ ] 20 個 MVP 術語都有指定出場句（`docs/glossary.md` §3.5），沒有只在詞表裡、遊戲中不會出現的孤兒。
- [ ] 關閉 drawer 後焦點回到原本的術語／chip；`Esc` 可關。

## 5. 雙語

- [ ] 預設英文；右上角可切繁中。
- [ ] 切換後不需要重新載入，版面不破。
- [ ] 英文比中文長 30–50%；按鈕不換行到擠壓圖示。
- [ ] 專有名詞一致：`power`、`life support`、`shield`、`food`、`health`、`science`、`Backpack`、`Knowledge Card`、`Cat Assist`。
- [ ] 中文沒有簡體字（用 `docs/glossary.md` 的詞表抽檢）。
- [ ] 數字用阿拉伯數字；負號用 `−` 不是 `-`（顯示層）。

## 6. 無障礙

- [ ] 全流程可用鍵盤完成：Tab 順序 HUD → 選項 → chip → 背包。
- [ ] `:focus-visible` 清楚可見（2px `--navy`）。
- [ ] 所有 icon-only 按鈕有 `aria-label`。
- [ ] 對比 ≥ 4.5:1（大字 3:1）；用 devtools 抽查三處。
- [ ] 顏色不是唯一資訊：資源同時有圖示＋數字。
- [ ] `prefers-reduced-motion` 時關閉視差與進場動畫。
- [ ] 知識卡 drawer 有 `role="dialog"`、`aria-modal`、焦點鎖定。
- [ ] 螢幕閱讀器（NVDA 或 VoiceOver）可讀出六個資源與三個選項。

## 7. 資料誠實

- [ ] 全站沒有「strong geomagnetic storm」。
- [ ] 「strong solar flare」只用在 X2.7 那張卡。
- [ ] 火星天氣只說「很冷」，沒有百分位排名。
- [ ] 資料面板標「snapshot, not live」，並列快照日期。
- [ ] 照片有 NASA ID 與 credit；沒有 NASA 標誌被當成背書。
- [ ] 開場旁白沒有說「NASA 偵測到火星地磁風暴」。
- [ ] 知識卡 Kp、重力（火星 0.38g，不是無重力）、閃焰／CME 三處用語正確。

## 8. 效能與穩定

- [ ] 首次載入 < 3 秒（4G 模擬）；第二次 < 1 秒（快取）。
- [ ] Console 沒有 error；沒有 404（字型、圖、JSON）。
- [ ] 圖片有 `width`／`height` 或 `aspect-ratio`，沒有明顯 CLS。
- [ ] 貓圖用 `srcset` 400/800/1200；事件插圖 `loading="lazy"`。
- [ ] 斷網後重新整理：快照資料仍可玩（若設計為離線優先）。
- [ ] 連續玩三局，記憶體與動畫沒有明顯變慢。
