# 品牌與視覺規範

> 《喵航員：火星基地》／Meowstronauts: Mars Outpost
> 最後更新：2026-11-11

---

## 1. 一句話定位

三隻貓太空人迫降火星，在補給船抵達前的七個 sol，靠玩家的選擇讓基地活下去。視覺是**溫暖的 3D 動畫電影**，不是暗色科幻 HUD，也不是純繪本。

## 2. 色彩

| Token | Hex | 用途 | 備註 |
|---|---|---|---|
| `--navy` | `#1B2A5B` | 主要文字、圓框、按鈕 | 角色頭像外框一律用此色 |
| `--ink` | `#172033` | 深色文字 | |
| `--paper` | `#F7F3EA` | 背景與面板底色 | |
| `--silver` | `#C9D2DC` | 銀白主題、次要資訊 | |
| `--amber` | `#E8A33D` | 金桔、警示、強調 | |
| `--coral` | `#E07A5F` | 危險、健康 | |
| `--teal` | `#4E8C8A` | 生命維持、成功 | |
| `--rust` | `#B85C38` | 火星土壤、次要強調 | |

規則：

- 文字與背景對比至少 WCAG AA（4.5:1；大字 3:1）。
- 顏色不能是唯一資訊來源；每個資源同時有圖示與文字。
- 角色專屬底色（頭像圓盤）：銀白 `#DCE4EE`、暗影 `#E9DDF2`、金桔 `#F6E3CC`。這是介面底色，不是角色配色。

## 3. 字體

- 中文：Noto Sans TC（Google Fonts，`display=swap`）。
- 英文／數字：Nunito 或 Baloo 2。
- 標題 28–36px、內文 16–18px、按鈕 18–20px；手機最小 16px。
- 不用全大寫標題、不用細體、不用裝飾性過強的字體。
- 英文是預設語言，版面以英文長度驗收（比中文長 30–50%）。

## 4. 角色資產

原始參考圖在 `docs/assets/characters/`，去背母檔在 `brand/source/`，輸出在 `brand/`。

| 檔案 | 尺寸 | 用途 |
|---|---|---|
| `avatar-silver-512.webp` | 512×512 | HUD、事件卡、對話框、任務報告 |
| `avatar-shadow-512.webp` | 512×512 | 同上 |
| `avatar-ginger-512.webp` | 512×512 | 同上 |
| `full-silver-800.webp` | 最長邊 800 | 事件卡、角色選擇、結局 |
| `full-shadow-800.webp` | 最長邊 800 | 同上 |
| `full-ginger-800.webp` | 最長邊 800 | 同上 |
| `favicon-180.png`、`favicon-32.png` | 180×180、32×32 | 網站 favicon、Apple touch icon |
| `favicon-{cat}-180.png` | 180×180 | 角色專頁或分享用 |
| `og-1200x630.jpg` | 1200×630 | 社群分享卡（暫用三貓合成，01 key art 完成後可替換） |

規則：

- 頭像圓盤＋`--navy` 10px 外框，所有角色一致。
- 不改花紋、眼睛顏色、服裝剪裁與背包；不新增第四隻貓。
- 全身圖是四足側面，不要翻轉（尾巴方向會錯）或裁掉腳掌。
- 生成圖不得有文字、Logo、浮水印；標題與按鈕由程式疊。

## 5. 元件

- **按鈕**：圓角 16px、高度 ≥ 48px、左侧圖示右側文字；按下狀態要有位移或顏色變化，不能只靠 hover。
- **事件卡**：`--paper` 底、圓角 20px、1px `--navy` 20% 邊框、淡陰影；類別標籤用 `--amber`／`--teal`／`--coral`。
- **HUD**：單列、圖示＋數字；寬度不足時省略文字標籤但保留 `aria-label`。
- **知識卡**：標題、1 句定義、2–3 句解釋、NASA 來源連結；手機橫放用右側 drawer 或中央 modal。
- **背包**：格狀圖鑑，未收藏顯示灰色剪影與「?」，不劇透。
- **任務報告**：星等、資源曲線、貓咪評論、新收藏、資料來源。

## 6. 圖像生成

- 統一前綴見 `docs/image-prompts.md`；完整 29 張 prompt、比例、檔名都在該文件。
- GEM 已內建三張參考圖；場景圖直接引用，不需每次上傳。
- 場景 16:9、對話頭像 3:4、事件卡 4:3、多角度表 3:2。
- 主體放中央 75% 寬 × 80% 高；外圍 10% 不放關鍵內容。
- 火星天空是奶油糖色，不是地球藍天；沒有液態水、雨、雪（霜可以）。
- 兒童友善：無火焰、受傷、血腥、恐怖表情。

## 7. 禁止

- 雙足站立、擬人手臂、手持工具、圍裙。
- 真實 NASA 標誌、任務徽章、可讀文字。
- 地球式藍天、綠地、湖泊、森林。
- 角色配色或比例與參考圖不一致。
